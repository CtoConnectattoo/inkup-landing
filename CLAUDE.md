# inkup-landing · instrucciones para Claude Code

## Contexto de la línea

Este proyecto pertenece a la línea **Inkup**: SaaS solo para estudios de tatuaje, que se verticaliza con depósitos y consentimientos. Comparte con Kalmaa solo la app de Meta y sus permisos de Instagram; Kalmaa es un producto aparte. Factura Connectattoo S.L.
Antes de trabajar, lee en Google Drive: Claude → "00 MAPA DE PROYECTOS · matriz y fuentes".
No reescribas la home de inkup.io con el enfoque "ManyChat en español": ese enfoque es de Kalmaa.

## Fuente de verdad

- Manda el Google Drive (carpeta "Claude"). Si algo de este repositorio contradice el Drive, gana el Drive: avisa a la persona antes de seguir.
- Producto, precios, marca y tono de Inkup: skills `inkup-producto`, `inkup-branding` e `inkup-tono-de-marca`.
- Público principal: tatuadores, estudios de tatuaje y piercers. Español neutro (España + LATAM).

## SEO y GEO

- El agente SEO/GEO semanal de inkup.io usa la carpeta `seo/` (config, keywords y consultas GEO) y el kit `CtoConnectattoo/seo-geo-kit`.
- `docs/seo/` es **material archivado de Kalmaa** (enfoque del 7 de noviembre, cuando era «Inkup · ManyChat en español»). No lo apliques a inkup.io ni sigas su PLAN, sus briefs o sus precios. Para Kalmaa manda el «00 BRIEF PARA CLAUDE CODE · Kalmaa» del Drive.
- Keywords compartidas con Kalmaa («alternativa a manychat», «automatizar mensajes instagram», «enlace whatsapp instagram»): no se empujan desde inkup.io.

## Cómo trabajamos

- Una fase = una rama + un pull request. Compila (`npm run build`) antes de abrirlo.
- Lo que se decida aquí que afecte a la estrategia se anota también en el Drive.
